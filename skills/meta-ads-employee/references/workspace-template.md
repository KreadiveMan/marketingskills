# Workspace Template

Copy these skeletons into `.agents/meta-ads/<brand-slug>/` at the start of a new engagement. Fill each file at its stage; keep `[EVIDENCE]`, `[OPERATOR]`, and `[HYPOTHESIS]` tags on every claim.
